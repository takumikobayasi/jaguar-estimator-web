# JUGGLER VIEW

Android版 `jaguar-estimator` のデータを知り合いと共有するための閲覧専用Web版です。

- スマートフォン・PC対応

- Google Apps Script経由のバックアップ読込み
- 朝予想／夕方候補／答え合わせ（PRED v0.2）

## 予想表示について

- 朝予想は対象日のデータを除外し、機種・履歴・曜日・間隔・位置の仮説適合度を表示します。
- 夕方候補は当日のG/B/Rと周辺台を加えた暫定判断です。
- 回転数と推定P(4以上)が十分な台を「座る候補」として表示します。
- 答え合わせの「4以上相当」は統計上の推定であり、実際の設定を断定する表示ではありません。
- 翌日の位置移動は実測と偶然期待を比較し、偶然との差だけを弱く予想へ反映します。
- 検証済み・保留・未検証の根拠は [`HYPOTHESES.md`](HYPOTHESES.md) に記録します。

## 修正と検証（WEB v1.16.1）

- 営業日の演算をUTCで統一し、日本時間で取得日・予想日・週の境界が1日ずれる問題を修正。
- 取得カレンダーの先頭に曜日合わせの空欄を追加。
- Apps ScriptはMIME形式に関係なく `jaguar-web-latest.json` を優先。固定名がない旧フォルダだけ全JSONの更新日時で選ぶ。
- 回帰テスト: `node --test tests/regressions.test.cjs`（Node.js 22以上）。日本時間・UTC・米国時間、閏日、週初め、固定名・旧形式バックアップを検証する。
- Apps Scriptの修正はGitHub Pagesの更新だけでは反映されない。[設定手順](apps-script/SETUP.md)に従い既存デプロイを更新する。
